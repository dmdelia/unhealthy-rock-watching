ASTREA SSP / THE PROGRAM

Independent research.
End to end.

ASTREA Solo Space Program is a single-person aerospace technology and astrophysics research program based in Germany.

01 / APPROACH

Hardware, software and analysis belong to the same system.

The program focuses on building and testing complete technical loops rather than isolated demonstrations: embedded flight software connects to sensors and actuators; scientific payloads create data; analysis pipelines turn that data into measurable results.

WHY ASTREA EXISTS

A program built to keep going.

ASTREA is meant to grow through systems, experiments, software, failures and iterations. The goal is not to present a finished space mission. The goal is to develop the capability to design, build, test and understand increasingly complex systems over time.

And yes: because it is fucking cool.
